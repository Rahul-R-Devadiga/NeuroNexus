# Google Form-like Web Form by NeuroNexus – Assignment Submission

## 🔧 Technologies Used

- HTML5
- CSS3
- No JavaScript or Backend used

## 📋 Features

- Collects the following fields:
  - Full Name
  - Contact Number
  - Address
  - Company Name
  - Email Address
  - Department (Dropdown)
  - Gender (Radio Buttons)
- Submit button included with hover effect
- Clean, minimal styling
- Form background separated from page background
- Box-shadow for subtle elevation effect

## ⚙️ Form Behavior

- The form uses `method="get"` to demonstrate submission behavior in a static environment.
- In a real-world application, `method="post"` would be used to securely submit form data.
- No backend or scripting (like JavaScript) is used, in accordance with assignment requirements.

## 📎 Notes

- CSS is written in a separate `styles.css` file.
- HTML and CSS strictly follow assignment constraints.
- The form does not actually store or process the data as there is no backend.

## ✅ Optional Enhancements Implemented

- ✅ Hover effect on submit button
- ✅ Background color contrast between form and page
- ✅ Minimalistic box-shadow
